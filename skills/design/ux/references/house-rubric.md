# Why the audit grades against a written house rubric

LLM judges asked to pick the better of two UX solutions score near chance against human preference, and they favour generated output over the human-written alternative.
A short list of written `when …, we …, not …` rules turns that taste call into a lookup: either the changed UI uses the house answer for a situation, or it does not, and the evidence is a `file:line` or a screenshot.

The rubric is graded in a fresh context, not the builder's, so the grader has no stake in the design it reviews.
The `not` clause matters as much as the `we` clause: it names the default an agent reaches for, which is the answer the house rejected.
